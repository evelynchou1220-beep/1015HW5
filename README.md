# 🐱🐟 打字貓咪 Typing Cat

老鼠扛著單字從夜空掉下來想偷魚乾，打出單字把牠們趕走、守護貓咪的魚乾！

**▶ 線上遊玩：https://evelynchou1220-beep.github.io/1015HW5/**

## 功能
- 英打／中打（支援注音、拼音輸入法）
- 生存模式（5 條魚乾）／限時模式（60 秒）
- 簡單／普通／困難三種難度，每 15 秒自動升級加速
- 連擊倍率計分、音效與動畫特效
- 結算顯示 WPM（中打為字／分）、正確率、最高連擊
- 各組合最高分自動保存在瀏覽器

## 操作
- 在下方輸入框打出畫面上的字即可消除
- `Enter`／空白鍵：送出　`Esc`：暫停／繼續

## 技術
單一 `index.html`（HTML + CSS + JavaScript），無外部套件；音效以 Web Audio API 即時合成，紀錄存於 localStorage。

本作品為課堂作業，透過與 AI 討論規格並以 Vibe Coding 方式完成。
